# CLIMACARAGUA

Site informativo sobre previsão do tempo, alertas de riscos climáticos e relatos colaborativos em Caraguatatuba.

> Este projeto foi iniciado com apoio do Lovable. O código pode ser executado e desenvolvido localmente.

## Desenvolvimento local

Requisitos: Node.js e npm (ou Bun).

```sh
npm install
npm run dev
```

Para gerar a versão de produção:

```sh
npm run build
```

Consulte o arquivo `.env` e configure as variáveis necessárias antes de executar integrações que dependam de serviços externos.
